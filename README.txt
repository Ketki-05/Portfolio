KETKI KANADE — PORTFOLIO WEBSITE

HOW TO OPEN
1. Extract the ZIP file.
2. Keep the folder structure unchanged.
3. Open index.html in a browser, or use VS Code with Live Server.

PROFILE PHOTO
The homepage expects your photo at images/profile.jpeg.
Copy your existing profile photo into the images folder and name it profile.jpeg.
If the photo is missing, the page displays a KK fallback.

CUSTOMIZE
- Colors, spacing, layout: css/style.css
- Mobile navigation and contact form behavior: js/script.js
- Page content: index.html, education.html, skills.html, projects.html, contact.html

CONTACT FORM
The form opens the visitor's default email app with a prefilled message. It does not send messages to a server automatically.

NOTES
The skill-bar percentages are illustrative and should be edited in skills.html to reflect your actual confidence level.
